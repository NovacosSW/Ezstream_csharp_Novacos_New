# EzStream 커버리지 시험 도구 배포본

ZIP 파일을 원하는 폴더에 풀고 `EzStream.CoverageTool.exe`를 실행합니다. 절대 경로를 설정할 필요가 없습니다.

## 대상 PC 사전 준비

- Windows x64용 .NET 9 Desktop Runtime
- `dotnet-coverage` 전역 도구

시험 도구는 다음 순서로 파일을 찾습니다.

1. `Harness\EzStream.Service.exe`
2. `Harness\EzStream.Tray.exe`
3. `Harness\EzStream.CoverageHarness.exe`
4. `Coverage.runsettings`

위 파일과 폴더의 상대 위치를 변경하지 마십시오. 시험 결과는 시험 도구 옆 `Results` 폴더에 저장됩니다. 설치 위치에 쓰기 권한이 없으면 `%LOCALAPPDATA%\EzStreamCoverageTool\Results`에 저장됩니다.

관리자 권한이 아닌 일반 PowerShell에서 다음 명령으로 `dotnet-coverage`를 한 번 설치할 수 있습니다.

```powershell
dotnet tool install --global dotnet-coverage
```

별도로 준비한 휴대용 `dotnet-coverage.exe`가 있다면 시험 도구 옆 `Tools` 폴더에 넣어도 됩니다. 시험 도구는 `Tools\dotnet-coverage.exe`를 먼저 사용하고, 없으면 Windows `PATH`에서 찾습니다.

시작할 때 필수 파일을 먼저 검사하므로 파일이 빠진 경우 Service나 Tray를 종료하지 않고 누락 경로를 표시합니다.

개발 PC에서는 배포 파일이 없을 때만 현재 저장소의 Debug 또는 Release 빌드 결과를 보조 경로로 검색합니다. 배포 PC에서는 `Harness` 폴더의 파일이 항상 우선됩니다.
